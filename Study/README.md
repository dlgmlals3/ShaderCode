# Shader Study Roadmap

목표: 한 달 동안 GLSL 셰이더를 매일 직접 만지면서, 작은 완성작을 계속 쌓는다.

핵심 방식:

> 이론을 먼저 완주하지 않는다. 만들고 싶은 장면을 고르고, 그 장면에 필요한 개념만 바로 공부해서 적용한다.

## 공부 원칙

1. 매일 최소 30분은 셰이더를 직접 실행한다.
2. 하루에 새 개념은 1개에서 2개까지만 잡는다.
3. 작품은 항상 `형태 -> 움직임 -> 색 -> 디테일 -> 연출` 순서로 만든다.
4. 처음부터 완성도를 욕심내지 않는다. 먼저 보이게 만들고, 그다음 예쁘게 만든다.
5. 매 작품마다 배운 점, 막힌 점, 다음 개선점을 기록한다.

## 진행 방식: 주석 보고 채워넣기

정답 코드를 읽지 않는다. 주석만 있는 빈 셰이더 파일을 받아서 직접 채운다.

### 버전 파일

작품 하나를 여러 버전 파일로 나눠 진행한다. 파일 이름은 `NN_작품이름.glsl` 이다.

```text
01_neon_tunnel.glsl   <- 1차: STEP 1~2  중심 UV, 동심원
02_neon_tunnel.glsl   <- 2차: STEP 3    시간 애니메이션
03_neon_tunnel.glsl   <- 3차: STEP 4    각도, 방사형 선
04_neon_tunnel.glsl   <- 4차: STEP 5    가짜 깊이감
05_neon_tunnel.glsl   <- 5차: STEP 6    네온 색
06_neon_tunnel.glsl   <- 6차: STEP 7    Glow
07_neon_tunnel.glsl   <- 7차: STEP 8    마무리 연출
08_neon_tunnel.glsl   <- 8차: STEP 9    실험과 변형
```

각 버전 파일의 구조:

- 이전 버전까지 완성한 코드가 위쪽에 들어 있다.
  - 파일이 미리 만들어져 있으므로, 새 버전을 열면 먼저 이전 버전에서 완성한 코드를
    `-> NN_neon_tunnel.glsl 에서 완성한 코드를 아래에 옮겨 붙인다` 표시 아래에 붙여넣는다.
- 새 STEP은 주석만 있고 코드는 비어 있다.
- 각 STEP 주석에는 세 가지가 적혀 있다.
  - `구현할 것`: 이 STEP에서 만들어야 하는 것
  - `알아야 할 것`: 코드를 쓰기 전에 이해해야 하는 개념과 질문
  - `확인`: 화면에 무엇이 보이면 완료인지

### 한 버전을 끝내는 순서

1. STEP 주석의 `알아야 할 것`을 먼저 읽고, 모르는 개념은 `examples/` 폴더에서 해당 예제만 본다.
2. 주석 아래 빈 줄에 코드를 직접 쓴다.
3. `확인` 조건이 화면에 보이면 다음 STEP으로 넘어간다. 안 보이면 넘어가지 않는다.
4. 주석 안의 숫자(`40.0`, `0.75` 등)를 바꿔보며 무엇이 달라지는지 본다.
5. 막히면 화면에 뭐가 보이는지 말하고 같이 본다. 정답을 통째로 받지 않는다.

### 다음 버전으로 넘어가기

1. 현재 버전이 완료되면 "채점"을 요청한다. 코드와 기록의 오개념을 짚어준다.
2. 통과하면 다음 번호 파일을 열고, 현재 버전의 완성 코드를 표시된 자리에 붙여넣는다.
3. 이전 버전 파일은 그대로 남겨서 진행 기록이 된다.

새 작품을 시작할 때 "다음 작품 진행하자"라고 말하면 그 작품의 버전 파일들이 만들어진다.

### 참고 자료 규칙

- `examples/`: STEP별 최소 예제. 막힌 STEP에 해당하는 것만 본다.
- 완성본 코드는 두지 않는다. 최종 예제(`neon_08_final_build.glsl`)는 마지막 STEP이 끝난 뒤에만 비교용으로 본다.

## 한 달 커리큘럼

### 1주차: 2D 좌표와 움직임

목표: 화면 좌표, 거리, 각도, 반복, 시간 애니메이션에 익숙해진다.

작품:

- Neon Tunnel
- Ripple

배울 개념:

- UV coordinate
- `vec2`, `vec3`, `float`
- `length`
- `atan`
- `sin`, `cos`
- `fract`
- `smoothstep`
- `mix`
- 시간 기반 애니메이션

완성 기준:

- 화면 중심을 기준으로 패턴을 만들 수 있다.
- 시간이 흐르면서 패턴을 움직일 수 있다.
- 색과 밝기를 직접 조절할 수 있다.

### 2주차: 파동과 노이즈

목표: 수식적인 패턴에서 유기적인 움직임으로 넘어간다.

작품:

- Water Ripple
- Energy Ball 또는 Flame

배울 개념:

- 거리 기반 파동
- 여러 파동의 합성
- hash
- value noise
- fbm
- 마스크와 그라데이션

완성 기준:

- 한 점에서 퍼지는 파동을 만들 수 있다.
- 여러 파동을 섞어서 복잡한 움직임을 만들 수 있다.
- noise로 불규칙한 흔들림을 만들 수 있다.

### 3주차: 절차적 텍스처

목표: 단순한 패턴을 재질처럼 보이게 만든다.

작품:

- Nebula
- Lava 또는 Marble

배울 개념:

- fbm 심화
- domain warp
- color palette
- contrast shaping
- vignette
- glow

완성 기준:

- noise를 여러 겹 쌓아 깊이감을 만들 수 있다.
- 색상 팔레트로 분위기를 제어할 수 있다.
- 정적인 텍스처에 흐름과 생동감을 넣을 수 있다.

### 4주차: Ray Marching 입문

목표: 2D fragment shader에서 3D scene shader로 넘어간다.

작품:

- Sphere + Box + Floor
- Infinite Corridor 또는 Chrome Sphere

배울 개념:

- ray origin
- ray direction
- SDF
- sphere tracing
- normal estimation
- diffuse lighting
- specular
- reflection
- fog

완성 기준:

- 카메라에서 광선을 쏘는 구조를 이해한다.
- SDF로 기본 도형을 만들 수 있다.
- 간단한 조명과 재질을 적용할 수 있다.

## 파일 구조

```text
Study/
  README.md
  01_neon_tunnel.glsl ~ 08_neon_tunnel.glsl   <- 버전별 작업 파일
  examples/
    neon_01_uv_grid.glsl                      <- STEP별 참고 예제
    ...
```

기록은 별도 로그 파일 대신 각 버전 파일의 주석에 남긴다. 배운 것, 막힌 점, 바꿔본 숫자를 해당 STEP 아래에 주석으로 적는다.

## 첫 시작

`01_neon_tunnel.glsl`을 열고 STEP 1부터 채운다.
